# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in DMForge, please report it privately — do not open a public GitHub issue.

Email **support@dmforge.org** with:

- A description of the vulnerability and its potential impact
- Steps to reproduce
- Any relevant logs, screenshots, or proof-of-concept code

We aim to acknowledge reports within 5 business days. DMForge handles customer personal data and payment data (via Stripe), so please give us a reasonable window to remediate before any public disclosure.

## Scope

This policy covers the DMForge application and API (this repository). Third-party services we integrate with (Firebase, Stripe, Twilio, GoHighLevel, LinkedIn) should be reported to those vendors directly.
